## Codex Rules

- Do not break existing working flows.
- Do not touch backend unless the task explicitly requires it.
- Do not rename routes, models, or database fields without explaining why.
- Prefer incremental UI improvements over full rewrites.
- Audit before implementation.
- Create documentation before major structural changes.
- Keep settings and admin structural first, not overbuilt.
- Use Reshaped as a base only after auditing compatibility.
- Use Atlantis selectively for patterns/components where useful.
- Use motion only where it improves understanding or feedback.
