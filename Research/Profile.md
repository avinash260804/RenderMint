

# Prepare a detailed profile framework with all the details

Here's the complete profile framework, structured as a component-by-component system that ties portfolio, contribution, and reputation into one resume-like identity page .

## Layout Hierarchy (top to bottom)

The profile follows a "trust-then-proof" reading order — the same pattern recruiters use when skimming a resume: identity first, credibility signal second, evidence third, references last.[^1][^2]

1. **Header Block** — avatar, username, tagline/bio, primary Studio, software stack tags, Honor level badge. Always visible, populated at onboarding.[^2]
2. **Status Signal** — one self-set tag: Open to critique, Seeking mentor, Available for collaboration, Open to work, or none. This is the "objective line" of the resume, user-editable anytime.[^2]
3. **Honor Score + Level** — total Honor number plus title (Member → Contributor → Critic → Expert → Mentor), the single glance-trust signal.[^1][^2]
4. **Honor Breakdown** — four sub-scores (Activity, Critique, Knowledge, Community) as mini bars, unlocking granular detail at Honor 50, showing *how* someone contributes rather than just how much.[^1][^2]
5. **Contribution Graph** — GitHub-style heatmap of 12 months' activity density, proving consistency over vanity metrics.[^2]
6. **Achievements/Badges** — milestone markers like "Solved 50 Problems" or "Rhino Expert," which read as quantified resume bullet points and appear only once earned.[^2]
7. **Content Tabs** — Posts, Answers, Spotlight Projects, Endorsements, Events Organized: the literal "work history" section.[^2]
8. **Endorsements** — peer testimonials naming a specific skill demonstrated, functioning as reference letters, becoming visible once Honor crosses 50.[^1][^2]
9. **Spotlight Link** — preview card pointing to the separate curated portfolio, keeping polished showcase distinct from raw contribution proof.[^1][^2]
10. **Critique Iteration Preview** — before/after thumbnails pulled from tracked critique threads, a growth narrative unique to Atelier.[^2]
11. **Honor Card Export** — shareable image/link for LinkedIn, CVs, and juries, unlocked at Honor 50+.[^2]

## Progressive Disclosure Ladder

Profile capabilities unlock gradually with Honor, so beginners never see tools they can't use yet — satisfying both "Beginner First" and "Progressive Disclosure" principles simultaneously:[^1]


| Honor range | Title | What unlocks on the profile |
| :-- | :-- | :-- |
| 0–50 | Member | Header, Status Signal, Contribution Graph starts, basic Content Tabs [^2][^1] |
| 50–250 | Contributor / Studio Helper | Endorsements section, Honor Breakdown detail, Honor Card export, Chapter creation ability [^2][^1] |
| 250–500 | Critic | Curated resource collections, Learning Path creation eligibility shown on profile [^2] |
| 500–1000 | Expert / Fellow | Challenge-judge eligibility badge, higher-weighted reaction visibility (Precise marks) [^2] |
| 1000+ | Mentor | Mentor badge, invited-to-judge indicator, full Critique Iteration showcase, platform-wide visibility boost [^2][^1] |

## Empty States and Beginner Coaching

For any user with zero posts, the profile should show a guided coaching card ("You haven't posted yet — here's how to get started") rather than a blank or shaming state, consistent with the platform's existing empty-state pattern used elsewhere. This keeps the profile feeling like a growth tool from day one rather than a leaderboard that excludes newcomers, reinforcing "Beginner First" and "Long-Term Learning".[^1][^2]

## Behavioral Rationale

Each component maps directly to a psychological anchor for a first-time viewer: the header answers "who," the Honor score answers "can I trust this," the content tabs answer "what have they actually done," and endorsements answer "who vouches for them" — collectively resolving the full profile in under the platform's "first ten minutes" clarity target. The progressive ladder additionally gives every active session a visible next milestone, turning reputation-building into a career-like long-term arc rather than a one-time badge collection.[^1][^2]
