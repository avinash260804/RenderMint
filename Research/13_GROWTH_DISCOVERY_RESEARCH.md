# Atelier Growth and Discovery Research

# Research Document Context

These files are created for **Atelier / Designers Hub**, a creative-professional community platform being reworked around forum discussions, structured critique, help posts, resources, profiles, dashboards, uploads, search, reputation, settings, moderation, and future admin systems.

The purpose of these files is not to provide final answers yet. Each file clearly defines **what data must be researched**, **why it matters**, **what questions to answer**, and **what output should be produced** before implementation decisions are made.

Use these files as research briefs for ChatGPT, Codex, manual web research, competitor analysis, product planning, and implementation planning.


## Purpose

This research defines how people will discover Atelier, understand its value, share content, and return after first use.

## Main research objective

Research organic growth, SEO, shareable pages, public profiles, invite strategy, launch messaging, community loops, and retention mechanisms for a creative-professional community.

## Data to research

### 1. Discovery channels

Research possible channels:

- Google search.
- Public critique pages.
- Public profile pages.
- Social sharing.
- Design communities.
- College/student groups.
- Designer Twitter/X.
- LinkedIn creative posts.
- Instagram design pages.

Data to collect:

- Which channels attract quality users.
- Which channels attract spam.
- What messaging works per channel.

### 2. SEO for community content

Research:

- Public thread SEO.
- Question/answer SEO.

- Discipline hub SEO.

- Public profile SEO.
- Resource page SEO.

Data to collect:

Research:

### 4. Public profiles as growth loops

Research:

- Public creator profiles.
- Portfolio-like contribution display.
- Reputation as social proof.
- Shareable profile links.

- Featured critiques/resources.

Data to collect:

- What profile data should be public.
- What makes users proud to share profiles.

- How to avoid exposing private data.

### 5. Invite and beta strategy

Research:

- Invite-only beta.
- Founding member roles.
- Discipline-specific cohorts.
- Referral invites.
- Waitlist pages.
- Early community promises.
- Beta feedback loops.

Data to collect:

- Whether Atelier should launch publicly or invite-only.
- How many early users are needed.

### 6. Retention mechanisms

Research:

- Notifications.
- Email digests.
- Saved posts.
- Followed disciplines.
- Weekly critique rituals.
- Challenge reminders.
- Replies to user posts.
- Reputation milestones.

Data to collect:

### 7. Landing page messaging

Research:

- Value proposition.
- Hero copy.
- Community explanation.
- Critique explanation.

Data to collect:
